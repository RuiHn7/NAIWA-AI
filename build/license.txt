NAI WA Desktop 许可协议与使用说明

版本：1.0.0
适用平台：Windows / macOS / Linux

一、软件说明
NAI WA Desktop 是一个本地优先的 AI Agent 桌面客户端。它本身不包含任何模型，
所有推理能力均来自你自己配置的第三方模型接口（OpenAI 兼容协议、Anthropic、
Google Gemini，或你自建的兼容服务）。会话记录、工作区文件、记忆条目、生成
图片与调用日志全部保存在本机，不上传至任何中继服务器。

二、你需要自己准备的东西
1. 模型接口地址与 API Key（在「设置 → 接入模型」中填写）。
2. 可选：Python 或 Node.js 运行时（用于「运行代码」工具）。
3. 可选：图片生成后端（OpenAI Images / Stability / SD WebUI / ComfyUI）。

三、数据与隐私
1. 所有数据存于本机用户数据目录，卸载时默认保留（如需清空请手动删除）。
2. API Key 通过操作系统安全存储加密保存（Windows DPAPI / macOS Keychain /
   Linux libsecret）。若系统不支持，会退回本地明文存储并在界面上标注。
3. 会话内容会按你的配置发送给你选择的模型服务商。请自行确认该服务商的数据
   处理条款。本软件不代理、不转存、不统计你的会话内容。
4. 审计日志（audit.jsonl）仅记录工具调用的批准/拒绝决定，用于回溯。

四、权限与安全
1. 默认权限模式为「提交前确认」：写文件、删文件、执行命令、安装依赖、发起
   外部网络请求、调用 MCP 外部工具，都会先弹出确认卡片。
2. 你可以在设置里切换为「完全放行」。切换后 Agent 将在工作区内直接执行上述
   操作而不再询问。请仅在你能接受该风险时开启。
3. 代码沙箱与命令执行均在你的用户权限下运行，没有额外的系统级隔离。不要在
   沙箱里运行来源不明的脚本。
4. 工作区目录之外的写入会被标记为高风险并单独确认。

五、免责
本软件按「现状」提供，不附带任何明示或暗示的担保。因使用本软件导致的模型
费用、数据丢失、文件损坏或其他损失，由使用者自行承担。

六、第三方组件
本项目使用 Electron、React、Vite、Zustand、marked、highlight.js、DOMPurify、
@tanstack/react-virtual 等开源组件，各自遵循其原始许可证。

七、接受条款
继续安装即表示你已阅读并同意上述内容。
